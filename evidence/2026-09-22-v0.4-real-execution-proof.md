## v0.4.0 correction
- Removed simulated Done transitions.

- Added explicit missing execution tasks.
- Added proof-gated Done contract.
- Required proof fields:
  - executor identity
  - request receipt
  - execution ID
  - terminal status
  - actual result/artifact
  - verification
  - durable evidence reference
- If a proof is missing, task remains Blocked/Running.
- Added RCA/RCS endpoint reachability checks.
- Added OpenAI server configuration check.
- Added execution proof column per task.
- Actual cost remains zero until execution evidence exists.
